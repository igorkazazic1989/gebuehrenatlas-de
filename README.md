# GebührenAtlas.de - GitHub Pages Ready
Dies ist eine vollständig SEO-optimierte, statische Website, die direkt auf GitHub Pages gehostet werden kann.

## Anleitung für GitHub
1. Erstellen Sie ein neues Repository auf GitHub (z.B. `gebuehrenatlas`).
2. Entpacken Sie diese ZIP-Datei und laden Sie alle Dateien in das Repository hoch (Push).
3. Gehen Sie in Ihrem GitHub-Repository zu **Settings -> Pages**.
4. Wählen Sie als Source den `main` oder `master` Branch und speichern Sie.
5. In wenigen Minuten ist Ihre Website unter `https://[ihr-benutzername].github.io/gebuehrenatlas` online!

## SEO-Features integriert:
- `robots.txt` und `sitemap.xml`
- Canonical Tags und Meta Descriptions auf jeder Seite
- JSON-LD FAQ Schema für Featured Snippets
- Semantisches HTML5 und schnelle CSS
